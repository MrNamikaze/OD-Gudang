# Model Files

Script `object_detection_publisher.py` memakai model MobileNet SSD Caffe.

Letakkan file berikut di folder ini:

- `MobileNetSSD_deploy.prototxt`
- `MobileNetSSD_deploy.caffemodel`

Dan labels default sudah disediakan di:

- `mobilenet_ssd_classes.txt`

Jika Anda ingin memakai model lain, cukup ubah path di `config.json` dan sesuaikan labels file-nya.
